# Prestige DataOps

Static marketing site (HTML, CSS, vanilla JS). No dependencies. One small asset-bundling step (below).
**Generic AI-automation website.** Industry pages can be added later (see the scaling guide).
How to add the next industry: [`docs/SCALING-TO-OTHER-INDUSTRIES.md`](docs/SCALING-TO-OTHER-INDUSTRIES.md).

Run locally: `python -m http.server 8080` (or `npx serve`) in this folder, then open http://localhost:8080/.

## Editing CSS / JS (bundling step)
Pages load **one** stylesheet and **one** script: `assets/dist/site.css` and `assets/dist/site.js`. Edit the sources in
`assets/css/` and `assets/js/`, then run:

```bash
python tools/build-assets.py
```

This rebuilds the bundles (minified CSS) and updates the `?v=` cache-busting hash on every page. The file order is listed at
the top of `tools/build-assets.py`; add new CSS/JS files there.

## Performance notes
- Effects are transform/opacity only; no blur filters, blend modes or backdrop blur; no full-screen overlays.
- Hero and CTA looping animations pause while offscreen (`data-pause-offscreen`); scroll work is one rAF-throttled handler.
- Fonts: two Google Fonts requests using variable ranges. Keep new effects compositor-friendly (see `assets/js/motion.js` header).

## Keeping pages in sync
There is no build step, so the **header, footer and head boilerplate are repeated in each page**. When you change the nav or
footer links, update every page (including /privacy/ and /terms/). The active nav link uses `aria-current="page"`. Pages in subfolders use `../` asset paths;
the homepage uses none.

## SEO
Per-page title, description, canonical, robots; Open Graph + Twitter; JSON-LD (Organization, WebSite, WebPage, Breadcrumb,
service/offer catalogs, FAQPage per page where there is an FAQ); sitemap; one h1 per page; skip link; reduced-motion support;
content visible without JS.
